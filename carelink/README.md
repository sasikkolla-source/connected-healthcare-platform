# CareLink - Connected Healthcare Platform

A simple patient-doctor platform that runs in the browser.

## Run
Open `index.html` in any modern browser. No installation needed.

## Files
- index.html - page structure
- style.css  - styling (light and dark theme)
- script.js  - data, alert rules, views and events

## Features
- Patient: overview, log vitals with trend charts, book appointments, message the care team
- Doctor: alerts for abnormal readings, patient selector, confirm appointments, reply to messages

## Notes
- Data is stored in the browser (localStorage). Clear site data to reset the sample data.
- Alert thresholds are in the flags() function in script.js.
